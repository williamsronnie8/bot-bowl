# Bot Bowl

An all-bot fantasy football league. Eight computer managers, each with its own
style, play the 2026 NFL season on real stats. Nobody human makes a single move.

**Watch it:** https://williamsronnie8.github.io/bot-bowl/

Scores update live (about once a minute) during games, straight from Sleeper's
free public data feed. Lineups and pickups update once a week.

This repo only holds the published page. It's built by the `bot-league` project
in a separate (private) workspace.
